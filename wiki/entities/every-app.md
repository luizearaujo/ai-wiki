# Every App (every-app)

> Organização que se descreve como "the open source personal software platform", mantenedora do OpenSEO e de outros projetos relacionados (SAM, Every-App SDK, um repositório de skills).

## O que é

A bio da organização no GitHub resume o foco: uma plataforma de software pessoal open source (everyapp.dev). Mantém o [OpenSEO](../repos/github.com/every-app/open-seo.md) como um dos produtos dessa plataforma, com servidor MCP e Agent Skills próprios.

## Repositórios e projetos

- [every-app/open-seo](../repos/github.com/every-app/open-seo.md) — stack de SEO self-hosted com servidor MCP e Agent Skills para pesquisa de palavra-chave, rastreamento de posição, backlinks e auditoria de site.

## Relevância no ecossistema

Exemplo de um domínio de produto tradicional (SEO) reformulado para ser operado por um agente via MCP e skills, em vez de só por uma pessoa em uma UI.
