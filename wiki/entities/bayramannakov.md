# Bayram Annakov (BayramAnnakov)

> Founder & CEO da onsa.ai; autor do [claude-reflect](https://github.com/BayramAnnakov/claude-reflect) e do [reflect-mod](../skills/github.com/bayramannakov/claude-reflect/reflect-mod.md), sistemas que capturam correções de prompt e as transformam em regras de `CLAUDE.md`/`AGENTS.md`.

## O que é

BayramAnnakov é o perfil de Bayram Annakov no GitHub, que se descreve como fundador e CEO da onsa.ai. Nesta wiki aparece como autor do `claude-reflect`, descrito pela própria API do GitHub como "a self-learning system for Claude Code that captures corrections, positive feedback, and preferences — then syncs them to CLAUDE.md and AGENTS.md", e do `reflect-mod`, reimplementação desse sistema como mod de Claude Code (hooks de função, verificação em tempo real), publicada no catálogo `claudemods.dev`.

## Repositórios e projetos

- [claude-reflect](https://github.com/BayramAnnakov/claude-reflect) — plugin Python original: 63 regexes na captura + verificação por modelo via `/reflect`; MIT. Não ingerido como página de repositório própria nesta wiki.
- [reflect-mod](../skills/github.com/bayramannakov/claude-reflect/reflect-mod.md) — versão mod (TypeScript, hooks de função) do mesmo sistema, documentada a partir da página de catálogo `claudemods.dev`.

## Relevância no ecossistema

Um dos poucos casos nesta wiki de um mesmo autor mantendo duas implementações do mesmo conceito — captura de correção → regra reutilizável — em formatos distintos (plugin Python multi-host vs. mod nativo do Claude Code), com uma tabela própria de comparação entre as duas publicada no catálogo.
