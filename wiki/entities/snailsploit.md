# SnailSploit (Kai Aizen)

> Pesquisador de segurança de IA generativa, autor do `claude-red`, biblioteca de 78 skills de segurança ofensiva para agentes.

## O que é

SnailSploit é o handle de **Kai Aizen**, identificado no README do `claude-red` como autor e pesquisador de segurança de IA generativa. O perfil mantém um site de pesquisa em [snailsploit.com](https://snailsploit.com) e publica o repositório que dá forma operacional ao seu trabalho: skills que ensinam agentes a conduzir avaliações ofensivas por superfície de ataque.

O README atribui a origem de parte do material à coleção de checklists ofensivos de [Sahar Shlichov](https://github.com/sahar042/offensive-checklist), sobre a qual muitas skills foram construídas.

## Repositórios e projetos

- [SnailSploit/Claude-Red](../repos/github.com/snailsploit/claude-red.md) — 78 skills ofensivas em 23 categorias, com instalação em Claude Code e Claude.ai e scripts de instalação por categoria.

## Relevância no ecossistema

O projeto exemplifica a especialização de bibliotecas de skills por domínio: em vez de um catálogo generalista, o `claude-red` cobre apenas segurança ofensiva e organiza o conhecimento por superfície de ataque. É também um caso de conteúdo dual-use distribuído como instruções para agentes — o que torna revisão, escopo e autorização responsabilidade do usuário.
