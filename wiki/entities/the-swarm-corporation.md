# The Swarm Corporation (Swarms)

> Organização que mantém o framework de orquestração Swarms e publica projetos de agentes, incluindo o AutoHedge, sistema autônomo de trading em Solana.

## O que é

The Swarm Corporation é uma organização no GitHub criada em 2024-04-22, sediada nos Estados Unidos, com a descrição "Building The Agent Economy". O perfil informa 164 repositórios públicos, cerca de 464 seguidores e o site [swarms.ai](https://swarms.ai), que comercializa a infraestrutura Swarms.

O framework Swarms é a base técnica declarada do [AutoHedge](../repos/github.com/the-swarm-corporation/autohedge.md): o README do projeto credita o Swarms como "AI agent framework". A organização publica também outros repositórios de agentes que não foram documentados nesta wiki.

## Repositórios e projetos

- [The-Swarm-Corporation/AutoHedge](../repos/github.com/the-swarm-corporation/autohedge.md) — hedge fund autônomo com pipeline Director → Quant → Risk → Execution; trading em Solana; MIT; ~6,4 mil estrelas observadas em 2026-10-19.
- `The-Swarm-Corporation/swarms` — framework de orquestração de agentes citado como base do AutoHedge; não documentado nesta wiki.
- Demais repositórios públicos: 164 no total, não inventariados nesta ingestão.

## Relevância no ecossistema

A organização combina um framework de orquestração (Swarms) com aplicações verticais, sendo o AutoHedge o exemplo financeiro. O padrão é semelhante ao de outros fornecedores de harness: o valor está na camada de coordenação e nas integrações, não apenas no modelo.

O AutoHedge, porém, é documentado por um README curto e promocional. A relevância da organização para esta wiki está mais no ecossistema de orquestração do que em evidência de qualidade do produto financeiro. **A verificar.**
