# ByteDance

> Organização que mantém o DeerFlow, super agent harness open-source para tarefas longas de pesquisa, código e criação.

## O que é

ByteDance é a empresa de tecnologia por trás de produtos como TikTok, Doubao e Volcengine, e mantém uma organização no GitHub com projetos open-source. No contexto desta wiki, aparece como mantenedora do [bytedance/deer-flow](../repos/github.com/bytedance/deer-flow.md).

O README do DeerFlow também menciona iniciativas irmãs e comerciais: o **LLM Space** (`deer-flow/llm-space`), ferramenta desktop para prototipar e depurar agentes; o **Coding Plan** da Volcengine, com recomendação de Doubao-Seed-2.0-Code, DeepSeek v3.2 e Kimi 2.5; e o **InfoQuest**, conjunto de busca e crawling da BytePlus integrado ao DeerFlow.

## Repositórios e projetos

- [bytedance/deer-flow](../repos/github.com/bytedance/deer-flow.md) — super agent harness 2.0 em Python/LangGraph, com subagentes, memória DeerMem, sandbox, skills, browser agêntico e canais de mensagem; licença MIT.
- [deer-flow/llm-space](https://github.com/deer-flow/llm-space) — ferramenta desktop para prototipar, inspecionar, reproduzir falhas e medir desempenho de agentes.
- Volcengine e BytePlus — serviços comerciais de modelos e busca citados no README.

## Relevância no ecossistema

O DeerFlow mostra uma empresa de grande porte publicando um harness completo e reescrevendo-o do zero, com documentação extensa de memória, sandbox, segurança e operação. É também um caso de **open-source com ecossistema comercial**: o runtime é MIT, mas o README promove serviços de modelos, busca e coding plan da própria empresa.

## Relações

- Colabora com: ecossistema LangChain/LangGraph; projeto irmão LLM Space.
- Associado a: Volcengine, BytePlus, Doubao, InfoQuest.
- Concorre com: outros harnesses de agentes e frameworks de orquestração, incluindo projetos open-source e produtos SaaS.
