# Anthropic (anthropics)

> Empresa de pesquisa em IA e criadora do Claude, mantenedora do repositório oficial de referência para [Agent Skills](../repos/github.com/anthropics/skills.md).

## O que é

anthropics é a organização no GitHub da Anthropic. Nesta wiki, aparece diretamente como mantenedora do repositório `anthropics/skills`, implementação de referência do padrão Agent Skills — com exemplos criativos, técnicos e enterprise, a especificação do formato e as skills de documento (docx/pdf/pptx/xlsx) que também alimentam o Claude em produção.

## Repositórios e projetos

- [anthropics/skills](../repos/github.com/anthropics/skills.md) — exemplos oficiais de Agent Skills, especificação do formato e skills de documento source-available; licença mista.

## Relevância no ecossistema

Anthropic é citada indiretamente em várias páginas desta wiki como criadora do formato Agent Skills e do Model Context Protocol, adotados por projetos de terceiros (ver [Agent skills](../concepts/agent-skills.md)). O repositório `skills` é a primeira página desta wiki em que a própria Anthropic é a mantenedora direta de um repositório ingerido.
