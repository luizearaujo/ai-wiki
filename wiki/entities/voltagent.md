# VoltAgent

> Organização por trás do framework open source de agentes de IA em TypeScript VoltAgent e da coleção awesome-claude-code-subagents.

## O que é

Segundo o perfil do GitHub, a VoltAgent se descreve como "AI Agent Engineering Platform built on an Open Source TypeScript AI Agent Framework", com sede nos Estados Unidos e site voltagent.dev.

## Repositórios e projetos

- [VoltAgent/awesome-claude-code-subagents](../repos/github.com/voltagent/awesome-claude-code-subagents.md) — coleção de 161+ subagentes para Claude Code em 10 categorias, instaláveis como plugins.

## Relevância no ecossistema

Mantém uma das maiores coleções curadas de subagentes especializados para Claude Code (25,9 mil estrelas em 2026-10-23), com política explícita de contribuição vendor-neutral e uma coleção irmã equivalente para o Codex (`VoltAgent/awesome-codex-subagents`, não ingerida nesta wiki).
