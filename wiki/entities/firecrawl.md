# Firecrawl

> "Supercharge your AI agents with data from the web and beyond." Organização mantenedora do [Firecrawl CLI](../repos/github.com/firecrawl/cli.md), de servidores MCP e de famílias de Agent Skills para busca, scrape e extração web.

## O que é

Firecrawl é uma plataforma de dados web voltada a agentes de IA. A organização no GitHub mantém o CLI (`firecrawl/cli`), o catálogo de skills (`firecrawl/skills`, não ingerido individualmente), o monorepo principal (`firecrawl/firecrawl`) e o repositório de workflows (`firecrawl/firecrawl-workflows`), além dos provedores de dados de terceiros agregados sob a marca "Alexandria".

## Repositórios e projetos

- [firecrawl/cli](../repos/github.com/firecrawl/cli.md) — CLI de busca, scrape, crawl, interação e extração autônoma por agente, com skills e servidor MCP próprios; licença não detectada pela API do GitHub.
- `firecrawl/skills`, `firecrawl/firecrawl`, `firecrawl/firecrawl-workflows` — repositórios irmãos citados no README do CLI, não ingeridos individualmente nesta wiki.

## Relevância no ecossistema

O Firecrawl é o segundo exemplo nesta wiki (depois de [D4Vinci/Scrapling](../repos/github.com/d4vinci/scrapling.md)) de uma ferramenta de scraping/busca web com camada explícita de agente — mas em um modelo de produto comercial hospedado, com créditos, provedores de dados de terceiros sob termos próprios (Alexandria) e um comando que pode se tornar o "provedor web padrão" de um agente, substituindo fetch/search nativos.

## Relações

- Mantém: [firecrawl/cli](../repos/github.com/firecrawl/cli.md).
- Contrasta com: [D4Vinci/Scrapling](../repos/github.com/d4vinci/scrapling.md) — biblioteca open source autoexecutável, sem camada de créditos ou provedores de terceiros.
