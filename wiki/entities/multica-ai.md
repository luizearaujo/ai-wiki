# multica-ai

> Organização que mantém o Multica, plataforma open-source para executar e gerenciar agentes de código reutilizáveis, e que hoje abriga o repositório `andrej-karpathy-skills`.

## O que é

Organização no GitHub criada em 2026-01-13, com 6 repositórios públicos e cerca de 2 mil seguidores observados em 2026-10-17. O README do repositório de diretrizes descreve o projeto principal da organização, `multica-ai/multica`, como "uma plataforma open-source para executar e gerenciar agentes de código com skills reutilizáveis"; o README do próprio Multica a resume como uma ferramenta para fazer humanos e agentes de IA trabalharem como um time, self-hostable.

A organização também abriga `multica-ai/andrej-karpathy-skills`. O README desse repositório continua apontando para o caminho antigo `forrestchang/andrej-karpathy-skills`, que redireciona para o novo; a transferência não é explicada no README.

## Repositórios e projetos

- [multica-ai/andrej-karpathy-skills](../repos/github.com/multica-ai/andrej-karpathy-skills.md) — diretrizes de comportamento para agentes em um único `CLAUDE.md`, derivadas das observações de Andrej Karpathy.
- [multica-ai/multica](https://github.com/multica-ai/multica) — plataforma open-source e self-hostable para gerenciar agentes de código e skills reutilizáveis; escrita em Go, ~53 mil estrelas observadas em 2026-10-17, último push em 2026-10-16. Licença reportada pela API como `NOASSERTION`.

## Relevância no ecossistema

A organização ocupa a camada de **distribuição e operação de agentes**: o Multica promete gerenciar agentes e skills reutilizáveis, e o repositório de diretrizes empacota comportamento de agente como texto instalável (arquivo `CLAUDE.md` ou plugin do Claude Code). Os dois projetos se complementam — um oferece a plataforma, o outro um conjunto de diretrizes de uso geral.

O repo de diretrizes é um caso de adoção expressiva: ~220 mil estrelas e ~22 mil forks em 2026-10-17, números que o colocam entre os repositórios mais populares do ecossistema de agentes. A popularidade é datada e não mede qualidade ou efeito real no comportamento dos agentes.
