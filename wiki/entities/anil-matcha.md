# Anil Chandra Naidu Matcha (Anil-matcha)

> Autor do Open-Generative-AI e de uma extensa série de repositórios "awesome" e wrappers de API em torno da plataforma MuAPI, de geração de imagem e vídeo por IA.

## O que é

O perfil do GitHub traz apenas "Curious" como bio. Mantém o [Open-Generative-AI](../repos/github.com/anil-matcha/open-generative-ai.md), estúdio self-hosted sobre a API da MuAPI, além de uma rede de repositórios relacionados citados no próprio README (listas "awesome" de apps e modelos generativos, exemplos de API por provedor) — nenhum documentado nesta wiki além do próprio Open-Generative-AI.

## Repositórios e projetos

- [Anil-matcha/Open-Generative-AI](../repos/github.com/anil-matcha/open-generative-ai.md) — estúdio self-hosted de geração de imagem/vídeo sobre 600+ modelos via MuAPI, com app desktop e dois motores de inferência local.

## Relevância no ecossistema

Opera no espaço de wrappers open source sobre uma API de geração de mídia comercial (MuAPI), com um modelo de negócio de white-label explícito no próprio README do produto.
