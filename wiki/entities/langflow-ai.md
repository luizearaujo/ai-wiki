# Langflow

> Organização mantenedora do Langflow, plataforma visual para construir e implantar agentes e workflows de IA como API ou servidor MCP.

## O que é

A bio da organização descreve o Langflow como "a powerful tool for building and deploying AI-powered agents and workflows". Além do repositório principal, a organização distribui um app desktop (Langflow Desktop) para Windows e macOS, embalando todas as dependências para quem não quer gerenciar ambiente Python.

## Repositórios e projetos

- [langflow-ai/langflow](../repos/github.com/langflow-ai/langflow.md) — builder visual de agentes/workflows com deploy como API ou MCP.

## Relevância no ecossistema

Langflow compete diretamente com Dify no espaço de plataformas visuais self-hosted para agentes/workflows de IA, com ênfase declarada em acesso ao código-fonte de cada componente e integração com observabilidade (LangSmith, LangFuse).
