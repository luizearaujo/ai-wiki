## Relevância no ecossistema

- **Direção de arte com processo:** o Impeccable organiza o trabalho em quatro modos (Persuade, Operate, Read, Experience), um playbook de 24 comandos e um piso de qualidade explícito, em vez de uma lista de proibições. É uma das abordagens mais estruturadas de [Design taste para agentes](../concepts/design-taste-para-agentes.md).
- **Contexto persistente:** a skill usa `PRODUCT.md` e `DESIGN.md` como estado do projeto, com detecção de drift; é um caso central de [Design system com agentes](../concepts/design-system-com-agentes.md).
- **Verificação no navegador:** o fluxo exige inspecionar o resultado renderizado nas dimensões reais, aproximando a skill de uma prática de [Auditoria de UX](../concepts/auditoria-de-ux.md).
- **Distribuição multi-harness:** o repositório publica a skill em diretórios de vários harnesses (`.agents/`, `.claude/`, `.cursor/`, `.gemini/`, `.github/`, `.codex`, `.opencode/`), além de plugin de Cursor e pacote VS Code.
