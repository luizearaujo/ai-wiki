# Remotion (remotion-dev)

> "Make videos programmatically." Organização mantenedora do framework Remotion e das suas [Agent Skills oficiais](../repos/github.com/remotion-dev/skills.md).

## O que é

remotion-dev é a organização do GitHub por trás do Remotion, framework que gera vídeo programaticamente a partir de componentes React. Mantém o repositório `skills`, com doze Agent Skills que cobrem criação de projeto, markup, render, mapas animados, legendas, interatividade no Studio e upgrade.

## Repositórios e projetos

- [remotion-dev/skills](../repos/github.com/remotion-dev/skills.md) — doze skills oficiais para agentes de código trabalhando em projetos Remotion; licença não detectada pela API do GitHub.

## Relevância no ecossistema

O Remotion já aparecia nesta wiki como um dos provedores de renderização citados por [calesthio/OpenMontage](../repos/github.com/calesthio/openmontage.md). Com a ingestão de `remotion-dev/skills`, passa a ter página própria como mantenedor, fechando o link bidirecional entre o orquestrador de pipeline (OpenMontage) e o fornecedor da tecnologia de renderização que ele usa.
