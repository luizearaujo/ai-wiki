# Open WebUI

> Organização mantenedora do Open WebUI e de um ecossistema de apps companheiros (terminal agêntico, agregador de bases de conhecimento, app desktop) em torno de uma interface self-hosted para qualquer modelo de IA.

## O que é

A bio da organização resume a missão: "On a mission to build the best AI user interface." Além do produto principal, mantém repositórios companheiros citados no próprio README do Open WebUI: `computer` (agente de código mobile-first), `open-terminal`/`terminals` (execução agêntica em container), `oikb` (ingestão de bases de conhecimento de 45+ fontes) e `desktop` (app nativo macOS/Windows/Linux).

## Repositórios e projetos

- [open-webui/open-webui](../repos/github.com/open-webui/open-webui.md) — plataforma de IA self-hosted, extensível e offline-capaz.

## Relevância no ecossistema

Open WebUI é, pelas estrelas observadas (156.432 em 2026-10-22), um dos repositórios de maior adoção já catalogados nesta wiki. Criado por Timothy Jaeryang Baek, hoje usa uma licença própria ("Open WebUI License") com cláusula de preservação de marca, em vez de uma licença OSI padrão.

## Relações

- Associado a: Ollama e qualquer API compatível com OpenAI, como provedores de modelo.
- Concorre com: [LangGenius](langgenius.md) (Dify), [Langflow](langflow-ai.md) — ambos builders de workflow/agente, enquanto Open WebUI é primariamente interface de uso; [LibreChat AI](librechat-ai.md) — mesmo espaço de interface self-hosted unificando múltiplos provedores de LLM com agentes e MCP.
