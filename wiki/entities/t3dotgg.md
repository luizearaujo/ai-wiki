## O que é

t3dotgg é o perfil de Theo Browne no GitHub. É CEO da Ping.gg, segundo seu perfil, e mantém o blog/site `t3.gg`. Nesta wiki aparece como autor do `tstack`, repositório que empacota as skills de revisão, merge e gestão de PR que ele usa no dia a dia.

## Repositórios e projetos

- [t3dotgg/tstack](../repos/github.com/t3dotgg/tstack.md) — nove skills de fluxo de pull request (review multi-modelo, merge autônomo, takeover de PR de terceiros, rebase/modernização) para Claude Code e Codex; MIT.

## Relevância no ecossistema

Autor também associado ao T3 Stack (`create-t3-app`) e, segundo o README do `tstack`, ao projeto `pingdotgg/t3code`, usado como dependência opcional de algumas das skills (`delegate_task` para subagentes em outros provedores de modelo). Representa um padrão de skills pessoais "limpas para uso geral", com fallback explícito para ferramentas nativas quando a dependência (`T3 Code`) não está presente.
