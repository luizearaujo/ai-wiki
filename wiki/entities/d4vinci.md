# D4Vinci

> Karim Shoair, especialista em web scraping no Egito, criador do [Scrapling](../repos/github.com/d4vinci/scrapling.md).

## O que é

D4Vinci é o perfil do GitHub de Karim Shoair, que se descreve como entusiasta de ciência da computação e segurança da informação, com foco declarado em web scraping. É o autor e mantenedor do Scrapling, framework Python de scraping com servidor MCP e Agent Skill para agentes de IA.

## Repositórios e projetos

- [D4Vinci/Scrapling](../repos/github.com/d4vinci/scrapling.md) — framework de web scraping com fetchers HTTP/browser stealth, spiders concorrentes, parsing adaptativo, CLI, servidor MCP e Agent Skill; BSD-3-Clause.

## Relevância no ecossistema

O Scrapling é um dos poucos projetos desta wiki em que o scraping tradicional (HTTP, parsing, crawling) convive, na mesma biblioteca, com uma camada explícita para agentes de IA: servidor MCP, Agent Skill versionada e geração de Markdown pronto para RAG sem LLM no processo.
