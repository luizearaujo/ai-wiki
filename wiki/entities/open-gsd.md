# Open GSD (open-gsd)

> Organização mantenedora do GSD Core, framework de engenharia de contexto e desenvolvimento orientado a spec para agentes de código.

## O que é

Segundo a bio da organização no GitHub, a Open GSD descreve sua missão como manter "o contexto limpo, o trabalho verificado e o histórico do git honesto" em setups de codificação com IA, que de outra forma degradam conforme a janela de contexto enche. Mantém o site opengsd.net e um servidor Discord de suporte comunitário.

## Repositórios e projetos

- [open-gsd/gsd-core](../repos/github.com/open-gsd/gsd-core.md) — framework que conduz agentes de código por um loop de cinco fases (Discuss, Plan, Execute, Verify, Ship), com subagentes de contexto limpo.

## Relevância no ecossistema

A Open GSD é a continuação do projeto GSD/"GSD 2", antes mantido sob `glittercowboy/get-shit-done` (depois `gsd-build/get-shit-done`, arquivado). A mudança de organização e a manutenção ativa do `gsd-core` posicionam o projeto como referência de "spec-driven development" multi-runtime, citado por comparações de skills de Claude Code como exemplo de framework não-trivial para projetos de várias sessões.
