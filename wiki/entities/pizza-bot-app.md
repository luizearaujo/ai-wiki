# Pizza Bot (pizza-bot-app)

> Organização que publica o Pizza Bot, inbox local-first para trabalho de agentes de IA de longa duração, desenvolvido na Amazon.

## O que é

`pizza-bot-app` é a organização GitHub que hospeda o Pizza Bot. Segundo o próprio README, o projeto "foi desenvolvido na Amazon" e testado internamente por mais de 2.000 usuários antes da abertura ao público; os "Executive Chefs" e "Sous Chefs" listados como contribuidores aparecem só por conta pessoal de GitHub, sem afiliação declarada no próprio README.

## Repositórios e projetos

- [pizza-bot-app/pizza-bot](../repos/github.com/pizza-bot-app/pizza-bot.md) — inbox local-first sobre DeepAgents/LangGraph, com desktop Electron, app web, CLI e backend standalone; Apache-2.0.

## Relevância no ecossistema

É o segundo exemplo documentado nesta wiki do padrão "inbox como interface de agente" (ao lado do [Agentic Inbox](cloudflare.md) da Cloudflare), mas resolvido como aplicação desktop local-first sobre LangGraph em vez de um cliente de e-mail cloud-native sobre Workers.

## Relações

- Colabora com: ecossistema DeepAgents/LangGraph; provedores de modelo integrados (Amazon Bedrock, Anthropic, Google Gemini, OpenAI, OpenRouter, Requesty, Ollama).
- Associado a: Amazon (origem declarada no README, sem organização GitHub própria associada ao projeto).
- Concorre com: outras soluções de inbox/orquestração para trabalho assíncrono de agentes, incluindo o Agentic Inbox da Cloudflare.
