# GitHub

> "How people build software." Organização oficial do GitHub, mantenedora do catálogo comunitário [awesome-copilot](../repos/github.com/github/awesome-copilot.md).

## O que é

A organização `github` no GitHub reúne projetos oficiais da empresa. Nesta wiki, aparece como mantenedora do `awesome-copilot`, catálogo de customizações do GitHub Copilot (agentes, instructions, skills, plugins) alimentado por desenvolvedores terceiros, não pela própria GitHub — o README do repositório é explícito sobre essa distinção.

## Repositórios e projetos

- [github/awesome-copilot](../repos/github.com/github/awesome-copilot.md) — catálogo comunitário de customizações do GitHub Copilot, com site de busca próprio e `llms.txt` para agentes; MIT.

## Relevância no ecossistema

É um caso de catálogo comunitário hospedado na organização oficial de uma empresa, mas explicitamente não auditado por ela — o mesmo padrão de "hospedagem oficial, conteúdo de terceiros" que vale a pena comparar com [ComposioHQ/awesome-claude-skills](../repos/github.com/composiohq/awesome-claude-skills.md), onde a curadoria é de uma empresa terceira em vez do próprio fornecedor do produto.
