# CJ Pais (cjpais)

> Criador do Handy, app de speech-to-text offline, e da versão CLI original em Python do mesmo projeto.

## O que é

O perfil do GitHub não traz bio pública; o trabalho documentado nesta wiki é o Handy, cujo README cita como projeto anterior o "Handy CLI", versão original em linha de comando Python, hoje mantida em repositório separado.

## Repositórios e projetos

- [cjpais/Handy](../repos/github.com/cjpais/handy.md) — app de desktop multiplataforma de transcrição de fala totalmente offline.

## Relevância no ecossistema

Handy é mantido com atenção declarada a detalhes de plataforma (Wayland vs. X11, teclados Apple, assinatura de release via minisign) raros em ferramentas pequenas de código aberto, e documenta publicamente limitações conhecidas em vez de omiti-las.
