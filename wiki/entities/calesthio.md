# calesthio

> Autor do OpenMontage, sistema open-source de produção de vídeo agêntico que transforma assistentes de código em estúdios de produção.

## O que é

`calesthio` é a conta que publica o OpenMontage no GitHub e mantém os canais do projeto (`@calesthioailabs` no X e `@OpenMontage` no YouTube). O README não fornece uma biografia ou estrutura organizacional; o contexto disponível é o próprio projeto.

## Repositórios e projetos

- [calesthio/OpenMontage](../repos/github.com/calesthio/openmontage.md) — sistema agent-first de produção de vídeo com 10+ pipelines, 100+ ferramentas, 60+ provedores e 700+ arquivos de skills/conhecimento; licença AGPL-3.0.
- Site do projeto: [openmontage.video](https://www.openmontage.video/).
- O README aponta para GitHub Sponsors (`github.com/sponsors/calesthio`).

## Relevância no ecossistema

O OpenMontage é um exemplo de **processo criativo completo empacotado como skills + pipelines** sobre um assistente de código, em vez de um produto SaaS de geração de vídeo. Ele também ilustra a tensão entre código aberto (AGPL-3.0), APIs pagas de provedores e acervos de mídia com licenças próprias.

## Relações

- Colabora com: comunidade do OpenMontage via GitHub Discussions; não há outras organizações declaradas no README.
- Associado a: Remotion, HyperFrames, FFmpeg e provedores de geração de mídia.
- Concorre com: ferramentas de geração de vídeo por prompt e suítes de edição assistida por IA.
