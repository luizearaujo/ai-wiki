# OpenHands

> Organização (antes `All-Hands-AI`) que constrói agentes de desenvolvimento de software abertos, hoje centrada no Agent Canvas, control center multi-backend para agentes de codificação.

## O que é

OpenHands se descreve, na bio da organização, como construtora de "AI software development agents for everyone, in the open". O GitHub redireciona a URL antiga `All-Hands-AI` para `OpenHands`, indicando renomeação da organização. O repositório principal (`OpenHands/OpenHands`) hoje documenta o Agent Canvas, um frontend self-hosted que conecta e automatiza agentes de codificação próprios e de terceiros; a lógica de agente vive em repositórios separados da mesma organização (`software-agent-sdk`, `typescript-client`, `automation`).

## Repositórios e projetos

- [OpenHands/OpenHands](../repos/github.com/openhands/openhands.md) — Agent Canvas, control center self-hosted para agentes de codificação sobre múltiplos backends.

## Relevância no ecossistema

A organização oferece infraestrutura própria (OpenHands Cloud/Enterprise) ao lado do software open source, e seu produto principal interopera deliberadamente com agentes concorrentes (Claude Code, Codex, Gemini CLI, Pi, OpenCode) via Agent-Client Protocol (ACP), em vez de competir diretamente com eles.

## Relações

- Colabora com: projetos compatíveis com ACP (Claude Code, Codex, Gemini CLI, Pi, OpenCode), integrados como backends do Agent Canvas.
- Associado a: `software-agent-sdk`, `typescript-client` e `automation`, repositórios irmãos que implementam a lógica de agente, cliente e automação.
