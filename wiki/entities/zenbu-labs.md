# zenbu-labs

> Organização mantenedora do [terminal-browser](../repos/github.com/zenbu-labs/terminal-browser.md), navegador Chromium real renderizado dentro do terminal.

## O que é

zenbu-labs é a organização GitHub que mantém o `terminal-browser`. O perfil da organização não publica nome, descrição ou blog. Nesta wiki, o escopo documentado se restringe ao que o README do `terminal-browser` publica.

## Repositórios e projetos

- [zenbu-labs/terminal-browser](../repos/github.com/zenbu-labs/terminal-browser.md) — navegador real (Electron/Chromium) dentro do terminal via protocolo gráfico kitty, com CLI compatível com `agent-browser`; MIT.

## Relevância no ecossistema

Aborda navegação web agêntica por um ângulo distinto dos já documentados nesta wiki: em vez de automação headless ou via protocolo do navegador (CDP), renderiza o navegador graficamente dentro do próprio terminal onde o agente de código já está rodando, priorizando colocar agente e site na mesma superfície visual.
