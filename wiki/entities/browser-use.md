# Browser Use

> Empresa americana mantenedora da biblioteca open source `browser-use` e de uma oferta comercial de navegadores em nuvem e agente hospedado para automação web.

## O que é

Browser Use mantém a biblioteca Python/TypeScript que dá a agentes LLM controle de um navegador real, ao lado de um conjunto de produtos relacionados: Browser Harness (CLI e versão JS), Browser Use Pi, Cloud SDK, Video Use e um harness para macOS. A empresa também mantém um modelo próprio, BU2, otimizado para automação de navegador, e um benchmark próprio (Browser Use Benchmark v2) para tarefas difíceis de navegação.

## Repositórios e projetos

- [browser-use/browser-use](../repos/github.com/browser-use/browser-use.md) — biblioteca/CLI/API open source para agentes de navegador.

## Relevância no ecossistema

Browser Use é um dos poucos projetos da wiki que combina biblioteca open source (MIT), modelo proprietário próprio e infraestrutura paga (navegador em nuvem por hora) no mesmo produto — modelo de monetização comparável ao de outros projetos freemium já documentados (ECC, Munder Difflin).
