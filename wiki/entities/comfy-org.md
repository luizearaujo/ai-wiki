# Comfy Org

> Organização que mantém o ComfyUI, GUI/backend de nós para modelos de difusão, após a transferência do repositório do mantenedor original `comfyanonymous`.

## O que é

A Comfy Org gerencia três repositórios interligados segundo o README do ComfyUI: o core (`ComfyUI`), o app desktop (`Comfy-Desktop`) e o frontend (`ComfyUI_frontend`), além do `ComfyUI-Manager` para extensões de terceiros. Mantém também uma oferta comercial paga, Comfy Cloud, para quem não tem hardware local.

## Repositórios e projetos

- [Comfy-Org/ComfyUI](../repos/github.com/comfy-org/comfyui.md) — GUI/API/backend modular de nós para modelos de difusão de imagem, vídeo, 3D e áudio.

## Relevância no ecossistema

ComfyUI é, pelas estrelas observadas (141.874 em 2026-10-23), um dos maiores repositórios já catalogados nesta wiki, e serve como camada de execução comum para diversos modelos abertos documentados ou citados aqui, incluindo [Wan-Video/Wan2.1](../repos/github.com/wan-video/wan2.1.md).
