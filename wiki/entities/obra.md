# Jesse Vincent (obra)

> Desenvolvedor em Berkeley, CA, ligado à Prime Radiant, autor do [superpowers](../repos/github.com/obra/superpowers.md), metodologia de desenvolvimento de software empacotada como skills para agentes de código.

## O que é

obra é o perfil de Jesse Vincent no GitHub. Nesta wiki aparece como autor do `superpowers`, framework que impõe design → plano → TDD → revisão como skills que disparam automaticamente em mais de uma dezena de harnesses de agente (Claude Code, Cursor, Codex, Gemini CLI, entre outros).

## Repositórios e projetos

- [obra/superpowers](../repos/github.com/obra/superpowers.md) — metodologia de desenvolvimento com skills compostas, subagentes por tarefa e TDD obrigatório; MIT.

## Relevância no ecossistema

Representa uma abordagem de metodologia explícita (e não apenas ferramentas pontuais) para disciplinar agentes de código através de skills — tema que se cruza com [Agent skills](../concepts/agent-skills.md) e [TDD para agentes](../concepts/tdd-para-agentes.md), e que se diferencia de coleções de skills avulsas por cobrir o ciclo completo de design a finalização de branch.
