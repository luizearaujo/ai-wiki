# Johnny (JohnnyVizz)

> Autor do [claude-kit](../repos/github.com/johnnyvizz/claude-kit.md), catálogo de skills e mods para Claude Code.

## O que é

JohnnyVizz é o perfil de Johnny no GitHub. O perfil não publica bio, empresa ou blog. Nesta wiki aparece como autor do `claude-kit`, que reúne uma skill de orquestração de subagentes (`savvy-flow`) e dois mods de interface (`savvy-progress`, `session-band`) para o Claude Code.

## Repositórios e projetos

Representa, ao lado de [hellosverre](hellosverre.md) ([claude-skins](../repos/github.com/hellosverre/claude-skins.md)), o padrão de mods de interface do Claude Code construídos sobre a API de hooks de função em early access — um ecossistema de terceiros customizando a interface e o fluxo de trabalho do Claude Code além do que skills e MCP cobrem.
