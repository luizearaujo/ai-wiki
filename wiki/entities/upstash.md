# Upstash (upstash)

> Plataforma de dados serverless, mantenedora do [context7](../repos/github.com/upstash/context7.md), servidor MCP e CLI que injetam documentação de bibliotecas atual e específica de versão no contexto de agentes.

## O que é

Upstash é a organização no GitHub da empresa homônima, descrita em seu perfil como "Serverless Data Platform". Nesta wiki aparece como mantenedora do Context7, projeto voltado a agentes de IA — uma extensão do foco original da empresa em infraestrutura de dados serverless para o problema de documentação desatualizada em LLMs.

## Repositórios e projetos

- [upstash/context7](../repos/github.com/upstash/context7.md) — servidor MCP e CLI (`ctx7`) para buscar documentação e exemplos de código atuais por biblioteca e versão; MIT.

## Relevância no ecossistema

Context7 é um dos poucos projetos nesta wiki focado especificamente em resolver desatualização de conhecimento de LLMs sobre bibliotecas de terceiros, via infraestrutura própria de indexação (parcialmente privada) exposta por MCP — tema ligado a [Model Context Protocol (MCP)](../concepts/model-context-protocol.md).
