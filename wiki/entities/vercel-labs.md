# Vercel Labs (vercel-labs)

> Organização experimental da Vercel ("Develop. Preview. Ship. Creators of Next.js."), mantenedora da coleção oficial [agent-skills](../repos/github.com/vercel-labs/agent-skills.md) e da CLI de automação de navegador [agent-browser](../repos/github.com/vercel-labs/agent-browser.md).

## O que é

vercel-labs é a organização de projetos experimentais e ferramentas da Vercel no GitHub. Mantém a coleção `agent-skills`, com oito skills de performance, design, escrita e deploy para agentes de código que trabalham em projetos Vercel, React, Next.js e React Native, e o `agent-browser`, CLI nativa em Rust para automação de navegador por agentes.

## Repositórios e projetos

- [vercel-labs/agent-skills](../repos/github.com/vercel-labs/agent-skills.md) — auditoria de custo/performance de projetos Vercel, boas práticas React/Next.js e React Native, guidelines de design web e de escrita, e deploy "claimable"; MIT.
- [vercel-labs/agent-browser](../repos/github.com/vercel-labs/agent-browser.md) — CLI Rust que controla o Chrome via CDP sem Node.js/Playwright, com snapshots de acessibilidade, servidor MCP e integrações para agentes; Apache-2.0.

## Relevância no ecossistema

É a primeira coleção de skills oficiais de uma plataforma de hospedagem/framework (Vercel/Next.js) documentada nesta wiki, ao lado de coleções equivalentes de outros fornecedores de produto ([anthropics/skills](../repos/github.com/anthropics/skills.md), [cloudflare/skills](../repos/github.com/cloudflare/skills.md), [remotion-dev/skills](../repos/github.com/remotion-dev/skills.md)). Com o `agent-browser`, a organização também passa a aparecer na linha de [navegação web agêntica](../concepts/navegacao-web-agentica.md), ao lado de projetos como [jo-inc/camofox-browser](../repos/github.com/jo-inc/camofox-browser.md).
