# openbq-org

> Organização que mantém o [OpenBB](../repos/github.com/openbq-org/openbb.md), Open Data Platform para dados financeiros; destino atual do repositório antes publicado como `openbb-finance/openbb`.

## O que é

openbq-org é a organização no GitHub por trás do ecossistema OpenBB: a plataforma de dados (`OpenBB`), o SDK de agentes (`openbb-ai`, `agents-for-openbb`), o template de integração de dados (`backends-for-openbb`), a documentação (`openbb-docs`) e uma lista de apps/widgets da comunidade (`awesome-openbb`). O perfil da organização no GitHub não publica nome, bio ou site — a identidade foi confirmada pela listagem de repositórios, que reproduz o catálogo histórico do OpenBB.

**Nota de proveniência:** a API do GitHub confirma que `openbb-finance/openbb` redireciona (HTTP 301) para o id de repositório atualmente hospedado em `openbq-org`, indicando transferência ou renomeação de organização, não um fork independente.

## Repositórios e projetos

- [openbq-org/OpenBB](../repos/github.com/openbq-org/openbb.md) — Open Data Platform: Python, Excel, MCP para agentes de IA e REST API sobre as mesmas fontes de dados financeiros; Apache-2.0.
- `awesome-openbb`, `backends-for-openbb`, `agents-for-openbb`, `agent-rita`, `openbb-ai`, `openbb-docs`, `openbb-brightquery` — repositórios irmãos citados na listagem da organização, não ingeridos individualmente nesta wiki.

## Relevância no ecossistema

O caso ilustra como a identidade canônica de um projeto pode mudar no GitHub (transferência de organização) sem que comandos, links e documentação externos sejam atualizados — o mesmo padrão já observado em outros repositórios desta wiki (ver `andrej-karpathy-skills` e `munder-difflin`).
