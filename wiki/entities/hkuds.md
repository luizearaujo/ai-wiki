# HKUDS (Data Intelligence Lab @ HKU)

> Laboratório de pesquisa da Universidade de Hong Kong que publica uma família de projetos de agentes — incluindo o Vibe-Trading, workspace financeiro com backtest, MCP e execução limitada por mandato.

## O que é

HKUDS é a conta no GitHub do **Data Intelligence Lab @ HKU** ("✨Data Intelligence Lab@HKU✨"), localizado em Hong Kong. Criada em 2022-11-14, mantém 93 repositórios públicos e cerca de 13,8 mil seguidores. O perfil não publica bio; o site associado é uma página pessoal em `sites.google.com/view/chaoh`.

O laboratório publica projetos de infraestrutura e aplicações para agentes, com adoção expressiva no GitHub. O [Vibe-Trading](../repos/github.com/hkuds/vibe-trading.md) é o projeto financeiro documentado nesta wiki.

## Repositórios e projetos

- [HKUDS/Vibe-Trading](../repos/github.com/hkuds/vibe-trading.md) — workspace de pesquisa financeira com 90 skills, 29 fontes de dados, backtest, 81 tools MCP e execução bounded-live; MIT; ~35,9 mil estrelas observadas em 2026-10-19.
- [HKUDS/nanobot](https://github.com/HKUDS/nanobot) — assistente pessoal de IA ultraleve; citado no README como parte do ecossistema.
- [HKUDS/AI-Trader](https://github.com/HKUDS/AI-Trader) — plataforma de sinais e copy trading agent-native; citada no README.
- [HKUDS/CLI-Anything](https://github.com/HKUDS/CLI-Anything) — iniciativa para tornar software agent-native; citada no README.
- [HKUDS/OpenSpace](https://github.com/HKUDS/OpenSpace) — skills de agente auto-evolutivas; citado no README e usado para publicar as 90 skills do Vibe-Trading.
- [HKUDS/ClawTeam](https://github.com/HKUDS/ClawTeam) — swarm intelligence para agentes; citado no README.
- Demais repositórios públicos: 93 no total, não inventariados nesta ingestão.

## Relevância no ecossistema

O HKUDS opera em duas frentes complementares: **pesquisa aplicada** e **distribuição de ferramentas**. O Vibe-Trading exemplifica essa combinação — um artefato de pesquisa (backtest, alphas, integridade de dados) empacotado como CLI, Web UI, pacote PyPI e servidor MCP, com skills publicadas em um serviço próprio (OpenSpace).

A escala de adoção do laboratório é notável, mas os projetos são novos e em evolução rápida. Números de estrelas e contagens de ferramentas devem ser lidos como afirmações datadas. **A verificar** a governança, os testes e a separação entre projetos acadêmicos e comerciais.
