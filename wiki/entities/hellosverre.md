# Sverre (hellosverre)

> Constrói software com IA; autor do [claude-skins](../repos/github.com/hellosverre/claude-skins.md) e de outros mods para Claude Code (`redgreen`, `smart-compact`, `mod-store`).

## O que é

hellosverre é o perfil de Sverre no GitHub, que mantém o blog `hellosverre.com`. Segundo a bio do perfil, constrói software com IA e está desenvolvendo os projetos "Metro" e "Remakecraft", além de buscar um contrato de aprendizagem em TI na Noruega a partir de agosto de 2027. Nesta wiki aparece como autor do `claude-skins`, mod que redesenha a transcrição do Claude Code em dezesseis temas.

## Repositórios e projetos

- [hellosverre/claude-skins](../repos/github.com/hellosverre/claude-skins.md) — mod `/skin`: tool calls, diffs, tabelas e Mermaid como cards, dezesseis temas, API para outros mods; MIT.

## Relevância no ecossistema

Autor também, segundo o README do `claude-skins`, do `redgreen` (resultados de teste em um painel ao lado do chat), do `smart-compact` (compacta após commit/testes verdes/antes do cache de prompt expirar) e do `mod-store` (navega e instala ~2.700 mods) — nenhum desses três ingerido nesta wiki. Representa, ao lado de [JohnnyVizz](johnnyvizz.md), o ecossistema de mods de terceiros para Claude Code construído sobre a API de hooks de função em early access.
